Add XmasDB.com to Radarr

XmasDB lists can be added directly to Radarr so movies from the collection can be automatically added to your library.

AVAILABLE LISTS

XmasDB Radarr feeds use a StevenLu-compatible JSON format containing movie identifiers suitable for Radarr.

Which list should you choose?

FULL COLLECTION

Adds and monitors movies from the complete curated XmasDB Hallmark Christmas collection. Select FULL COLLECTION and use /json/all.json.

YEAR LISTS

Follow only movies from a particular year by selecting that year and using its JSON list, for example /json/2025.json.

ACTOR LISTS

Actor-specific Radarr feeds are available from individual actor pages. They contain only movies featuring that actor from the curated XmasDB collection, not the actor's complete filmography.

FULL COLLECTION = every movie in the curated collection

YEAR LISTS = only movies from the selected year

ACTOR LISTS = only collection movies featuring that actor

2026 = only 2026 movies

2025 = only 2025 movies

2024 = only 2024 movies

Important note

If someone subscribes Radarr to a specific year JSON file, future movies added to other years will not be included in that Radarr list.

RADARR SETUP

Important

Use StevenLu Custom in Radarr — NOT Custom Lists.

  1. 1

    Open Radarr

    Open your Radarr web interface.

  2. 2

    Go to Import Lists

    Go to: Settings → Import Lists.

  3. 3

    Add an Import List

    Click + Add Import List.

  4. 4

    Choose StevenLu Custom

    Under Advanced List, select StevenLu Custom. Do NOT choose Custom Lists.

  5. 5

    Name Your List

    Give the list a name, for example: XmasDB – Hallmark Christmas Movies.

  6. 6

    Configure Your Preferences

    Select your preferred Quality Profile, Root Folder, Monitor setting, and Minimum Availability.

  7. 7

    Paste the Feed URL

    Paste the chosen XmasDB JSON URL into List URL.

  8. 8

    Test the List

    Click Test. Radarr should report that movies were returned.

  9. 9

    Enable and Save

    Enable the list and click Save. Optionally enable Search on Add if you want Radarr to immediately search for newly added movies.
