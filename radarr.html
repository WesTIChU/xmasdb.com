Add XmasDB.com to Radarr

Follow these steps to add Hallmark Christmas movie feeds to Radarr. Choose the complete collection, an individual year, or use an actor-specific feed from that actor's page.

Choose Your Feed

Select whether you want every movie or a single specific release year. Actor-specific feeds are available from the relevant actor page.

Which list should you choose?

"Want every Hallmark Christmas movie?"

Select FULL COLLECTION and use /movies.json.

"Only want movies from a particular year?"

Select that year and use its individual JSON list (e.g. /json/2025.json).

"Want movies featuring a particular actor?"

Use the actor-specific JSON list shown on that actor's page. It contains only matching movies from this collection.

FULL COLLECTION = every movie in the catalogue

ACTOR LISTS = only collection movies featuring that actor

2026 = only 2026 movies

2025 = only 2025 movies

2024 = only 2024 movies

Important note

If someone subscribes Radarr to a specific year JSON file, future movies added to other years will not be included in that Radarr list.

Step-by-Step Radarr Setup Guide

  1. 1

    Open Radarr

    Launch and open your Radarr web interface in your browser.

  2. 2

    Navigate to Import Lists

    In the left navigation menu, go to: Settings → Import Lists.

  3. 3

    Add a New List

    Click the large + (Plus) button to open the list selector modal.

  4. 4

    Select Custom List Type

    Select the appropriate custom list type that supports a StevenLu-compatible JSON list (typically labeled Custom List or StevenLu Custom List in current Radarr releases).

  5. 5

    Name Your List

    Give the list a clear, recognizable name, for example: XmasDB.com (or XmasDB.com 2025 if using a specific year).

  6. 6

    Paste the List URL

    Paste the copied XmasDB.com JSON URL into the List URL field.

  7. 7

    Configure Your Preferred Radarr Options

    Configure your import settings according to your media server setup. Users should choose their own preferred Radarr settings rather than hard-coding them:

    • Quality Profile: Select your desired release resolution (e.g. Any, 1080p, 720p).
    • Root Folder: Select your target movies directory or holiday library folder.
    • Monitor: Choose how Radarr should monitor newly imported movies (e.g. Movie Only, None).
    • Tags: Optionally add a tag like hallmark or christmas for easy organization.
  8. 8

    Test the Connection

    Click the Test button. Radarr will fetch the JSON feed and confirm valid communication with a green checkmark.

  9. 9

    Save the List

    Click Save to store the new import list configuration.

  10. 10

    Radarr Syncs Automatically

    Radarr can then import movies from the selected Hallmark Christmas list according to your configured Import List schedule and settings.
